# tag · NovelAI 提示词 tag 选择器

一个**纯静态**的 Danbooru tag 选取 / 组合 / 加权 / 随机抽取工具，部署形态：GitHub Pages（无后端、无依赖）。

站点地址：<https://sora887.github.io/tag/>

---

## 功能

1. **分类点选词库** — 18 个大分类（人物构成 / 头发 / 脸部 / 表情 / 躯体 / 服装 / 配饰 / 动作 / 画面构图 / 布景 / 光照 / 氛围特效 / 环境场所 / 背景元素 / 物种 / 艺术风格 / R18 / 画师），共 362 个小分类、12,109 条词条。
2. **已选区拖拽排序** — 顺序即提示词优先级（HTML5 拖拽，桌面端）。
3. **每条 ± 加权** — 点 `+`/`−` 改变嵌套层级，实时反映到输出。
4. **加权语法切换** — `{ }`（NovelAI）⇄ `( )`（通用 / SD 系）；减权统一用 `[ ]`。
5. **正向输出框 + 复制** — 一键复制到剪贴板（含 execCommand 降级）。
6. **反向提示词框** — 预置常用负面串，可编辑。
7. **恢复默认负面串** — 一键还原。
8. **localStorage 持久化** — 刷新后已选、权重、反向串、开关状态全部保留。
9. **中英文显示切换** — 只显示中文（点击仍插入英文 tag）或只显示英文。
10. **R18 开关** — 关闭时隐藏 NSFW 分类。
11. **中文对照** — 词库自带中文名，无需在线翻译。
12. **全库搜索** — 中英混搜、空格多词组合匹配，结果按小分类分组。
13. **自定义导入** — 逗号/换行分隔批量加入。
14. **右键菜单** — 在 Danbooru 预览该 tag / 复制 tag。
15. **随机抽取（默认 1girl）** — 见下方规则。

> 不包含：D 站单图反推导入（原站自带该功能）、Turnstile 人机验证（纯静态站无后端 API 可保护）、引流模块。

## 随机抽取规则

- 固定种子 `1girl`（单人）。
- 默认只从 人物构成 / 头发 / 脸部 / 表情 / 服装 / 配饰 / 动作 / 画面构图 / 光照 / 氛围特效 / 布景 / 环境 里抽；**躯体元素、物种生物、画师、NSFW、艺术风格默认关闭**，可在随机面板里自行勾选。
- 每类随机抽 1–2 个小分类（画面构图最多 2 个），小分类内部随机取 1 条；有 35% 概率优先抽"3–6 tag 短语"。
- 互斥保护：
  - 多人词（`2girls` / `multiple_girls` / `1boy` …）一律排除；
  - 取景裁切（upper/lower body、cowboy shot…）、时间、天气、姿态（站/走/躺/坐/跪/跳）各最多 1 个；
  - 发色、瞳色最多 1 种；
  - 视角对冲突（from above ⇄ from below、from behind ⇄ front view、pov ⇄ 背面等）；
  - 职业互斥（现实职业 ⇄ 幻想职业 只取一类）；表情只取 1 个小分类；
  - `bald` 与任何发型互斥。
- 关闭 R18 时，内衣 / 情趣 / 比基尼 / 泳衣 / 透视等小分类不参与抽取。

## 目录结构

```
tag/
├── index.html          # 单页应用
├── css/style.css       # 干净简洁风（白卡 + 浅灰底 + 单一强调色）
├── js/app.js           # 全部逻辑（无构建、无依赖）
└── data/
    ├── base/           # 16 个原始词库（来自 idlecloud tag_select，MIT）
    ├── extra/          # 10 个补充词库（挑染/细节穿搭/构图/打光/氛围/表情/姿势/布景/配饰/风格）
    └── merged/         # 合并产物 + index.json（前端实际加载这里）
```

## 本地预览

`fetch()` 无法读 `file://` 下的 JSON，所以不要直接双击打开：

```bash
cd tag
python -m http.server 8000
# 打开 http://127.0.0.1:8000
```

## 部署到 GitHub Pages

1. 推到 `sora887/tag` 的 `main`。
2. Settings → Pages → Source:`Deploy from a branch` → `main` / `/ (root)`。
3. 等 1 分钟，访问 <https://sora887.github.io/tag/>。

## 词库来源与加工

- 基础 16 类：移植自 [YILING0013/tag_select](https://github.com/YILING0013/tag_select)（MIT License © 2025 YILING0013），原始实现改编自 [WolfChen1996/NovelAI-tag-generator](https://github.com/WolfChen1996/NovelAI-tag-generator)。
- 补充 10 类（约 900 条）：由本项目新增，覆盖挑染/发型组合、细节穿搭短句、构图与取景、打光、氛围特效、表情细化、具体坐姿、布景色、区域配饰、艺术风格。
- 词条校验：单 tag 尽量对照离线 Danbooru 索引核对过规范名；索引快照未收录的常用词（如 `rim lighting`）按自然语言保留。
